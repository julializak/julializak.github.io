Saint Mary's College · Fall 2025

Senior Capstone

A semester-long project where I brought together mathematics, computer science, and real-world language analysis.

Overview

I explored how we can represent and analyze text using TF-IDF, vectorization techniques, and logistic regression. Using a small dataset of Saint Mary's course descriptions, I built and trained a model that identifies how Mathematics and English Literature course descriptions differ through their term-frequency patterns and feature weights.

Read the abstract

This project explores how textual data can be represented and analyzed using foundational mathematical tools from statistics and information retrieval. We focus on the task of classifying a subset of Saint Mary’s College course descriptions as either Mathematics (MATH) or English Literature (ENLT) using a fully interpretable model. After cleaning and tokenizing the dataset, each description is transformed into a numerical vector using the Term Frequency-Inverse Document Frequency (TF-IDF) weighting scheme, which quantifies both the prominence and distinctiveness of words across the corpus. Logistic regression is then applied to these TF-IDF features to model the probability that a description belongs to the MATH category through the log-odds framework. We examine how individual terms influence predictions, interpret the fitted coefficients, and evaluate the model’s performance on the dataset. This project highlights how transparent mathematical methods can form a strong foundation for understanding more complex natural language processing systems.

The Motivation

Understanding how computers process language has become central to data science and modern artificial intelligence. We interact with these applications every day, from voice assistants like Siri and chatbots to text message autocorrect, spam filters, and translation tools like Google Translate. Learning the foundational concepts behind how computers process language is the core of this project, and the first step toward understanding these larger models. To build that foundation, I chose text classification as my focus.

Language surrounds nearly every aspect of our lives, and understanding language can be hard, especially for machines. Humans can understand meaning, but machines only interpret numbers, so we have to turn the text into machine-interpretable information, and for this project I chose TF-IDF.

How the Project Evolved

I started with a big goal: understand how machines learn and generate language, following the same road map that leads from RNNs to Transformers and today's Large Language Models.

Through that research and feedback from my advisor, I realized how much is happening inside those larger models. Rather than treating them as a black box, I narrowed my scope to a model I could explain at every step: TF-IDF features with logistic regression. My goal shifted from knowing that a model works to understanding why it works.

Three Talks, One Semester

The project was built around a progression of three talks, each longer and more technical than the last. Every talk ended with an open Q&A panel from my advisor and classmates.

  1. Talk 1 · 20 minutes

    Laying the Foundation

    An introduction to machine learning and natural language processing, tracing the path from early rule-based systems to logistic regression, RNNs, and Transformers.

  2. Talk 2 · 30 minutes

    Applying It to Real Data

    A walk through TensorFlow's IMDB sentiment classification tutorial, covering the full workflow of loading and splitting data, vectorizing text, training a model, and evaluating its performance.

  3. Final Talk · 45 minutes + 15-minute technical Q&A

    My Model, Start to Finish

    The full TF-IDF and logistic regression model built on Saint Mary's course descriptions, from the math behind it to the results. It closed with a technical Q&A from my advisor, guests, and another professor in the department.

Alongside the talks, the paper went through its own milestones: an initial draft before the second talk, then alpha and beta versions, and a final paper delivered to three faculty readers a week before the final talk.

My Approach

  1. Built the dataset. I collected 20 course descriptions from the Saint Mary's College Bulletin, 10 Mathematics and 10 English Literature, and labeled each one.
  2. Cleaned the text. I lowercased each description, removed punctuation and common stop words, and split it into individual tokens.
  3. Turned words into numbers. I used TF-IDF to give each word a weight based on how often it appears in a description and how distinctive it is across all of them.
  4. Trained the model. I fit a logistic regression classifier on those TF-IDF features to predict whether a description belongs to Math or English.
  5. Interpreted the results. I looked at the model's coefficients to see which words pushed a prediction toward each subject, and tested it on a description it had never seen.

Results

The model correctly classified all 20 course descriptions it was trained on. With a dataset that small, that mostly shows the model learned the training examples, so the real test was something new: I gave it a statistics course description it had never seen, and it predicted Mathematics with about 58.5% probability. Words like "math," "modeling," and "topics" pushed the prediction toward Math, and because every word has its own weight, I could explain exactly why the model made that call.

What I Learned

The biggest lesson was the value of a strong foundation. Simple, interpretable models use the same core ideas as RNNs and Transformers: representing text as numbers, weighting the words that matter, and learning parameters from data. Working through every step by hand gave me a much clearer picture of how those larger models work.

I also saw the limits of this approach. TF-IDF treats text as a "bag of words," so it ignores word order and context, which is exactly the problem more advanced language models are built to solve. Beyond the technical side, this project taught me how to scope a large problem, take feedback, and explain complex math to a general audience across three talks and a final paper.

Key Concepts

Large Language Models

An LLM is a type of foundational model trained on large amounts of data. This training allows it to understand and generalize natural language, often producing text that sounds human-like. Because of these foundational capabilities, a single LLM can drive many different applications and handle a wide range of tasks. Well-known examples include OpenAI's GPT-3 and GPT-4 and Google's Gemini.

Machine Learning

ML is when computers learn from data in order to make predictions, without being explicitly programmed with rules. Instead of an engineer writing every rule by hand, the model discovers these rules from examples, like learning whether a movie review is positive or negative by studying thousands of labeled reviews.

Natural Language Processing

NLP is the practice of using computers to interpret and work with human language. Natural languages have evolved over time through everyday use, unlike programming languages, which are designed from a fixed set of rules before anyone uses them. This evolution is what makes them “natural,” but it also makes them messy, ambiguous, and always changing, and that is what makes them hard for machines to understand.

Recurrent Neural Network

An RNN is a type of deep neural network designed for sequential data, like sentences or time series. It reads inputs one step at a time and keeps a "memory" of what came before, so each prediction is shaped by the earlier input, as well as the current one.

Term Frequency - Inverse Document Frequency

TF-IDF is a weighted representation that highlights important, distinctive terms. This combination scales each word by both how often it appears in a description (TF) and how distinctive it is across the corpus (IDF). This weighting scheme comes from information retrieval, where the objective is to measure the relevance of a term based on both its presence in a document and its distribution across the entire collection of documents. TF-IDF provides a way to quantify that informativeness. It helps to emphasize category-specific words while reducing the influence of generic terms that occur in the majority of the documents.
