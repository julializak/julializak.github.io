Saint Mary's College · Fall 2025

Senior Capstone

A semester long project where I brought together mathematics, computer science, and real-world language analysis.

Overview

I explored how we can represent and analyze text using TF-IDF, vectorization techniques, and logistic regression. Using a small dataset of Saint Mary\'s course descriptions, I built and trained a model that identifies how Mathematics and English Literature course descriptions differ through their term-frequency patterns and feature weights.

The Motivation

Understanding how computers process language has become central to data science and modern artificial intelligence. On a large scale, these are applications we interact with on a day to day basis. Everything from speaking assistant like siri, chat bots, to text message autocorrect, filters for spam messages, and language translate tools like google translate. Understanding the foundational concepts of how computers process language is the core of this project and will get me to understanding these larger models. I chose text classification as my focus.

Language surrounds nearly every aspect of our lives, and understanding language can be hard, especially for machines. Humans can understand meaning, but machines only interpret numbers, so we have to turn the text into machine-interpretable information, and for this project I chose TF-IDF.

Key Concepts

Large Language Models

Machine Learning

ML is when computers learn from data in order to make predictions, without being explicitly programmed with rules. Instead of an engineer writing every rule by hand, the model discovers these rules from examples, like learning whether a movie review is positive or negative by studying thousands of labeled reviews.

Natural Language Processing

NLP is the practice of using computers to interpret and work with human language. Natural languages have evolved over time through everyday use, unlike programming languages, which are designed from a fixed set of rules before anyone uses them. This evolution is what makes them “natural,” but it also makes them messy, ambiguous, and always changing, and that is what makes them hard for machines to understand.

Recurrent Nueral Network

A RNN is a type of deep nueral network designed for sequential data, like sentences or time series. It reads inputs one step at a time and keeps a "memory" of what came before, so each prediction is shaped by the earlier input, as well as the current one.

Term Frequency - Inverse Document Frequency

TF-IDF is a weighted representation that highlights important, distinctive terms. This combination scales each word by both how often it appears in a description (TF) and how distinctive it is across the corpus (IDF). This weighting scheme comes from information retrieval, where the objective is to measure the relevance of a term based on both its presence in a document and its distribution across the entire collection of documents. TF–IDF provides a way to quantify that informativeness. It helps to emphasize category specific words while reducing the influence of generic terms that occur in the majority of the documents.
