Skills: Extending Agent Capabilities

CSE 60556: Large Language Models: Basics and Practice

For this graduate course, I co-presented a lecture on agent skills: reusable packages of instructions and code that teach AI agents how to do specific tasks well. I led Part 1, which brought together six recent papers to cover what skills are, how agents organize and combine them at scale, whether they actually improve performance on real coding tasks, and when one agent with skills can replace a multi-agent team. My co-presenter, Yinuo Yang, led Part 2, on how agents learn and improve skills on their own. I built my slides in LaTeX/Overleaf and also attached Python demo scripts that use a local LLM (Ollama) to generate PowerPoint, Word, and Excel files, given to me in the readings.

Key Concepts

Agent Skill

A reusable package of instructions, scripts, and resources, usually a folder with a SKILL.md file, that gives an AI agent the know-how for one specific kind of task. Built-in examples include skills for creating PowerPoint, Excel, Word, and PDF files.

Progressive Disclosure

Loading information only as it's needed. An agent always sees each skill's short name and description, reads the full instructions only when a skill is relevant, and opens linked files only if the instructions call for them. This keeps the agent focused and saves tokens.

Multi-Agent System

A setup where several AI agents, each with its own role, pass work between each other to finish a task. It can be powerful, but every handoff costs extra API calls, tokens, and time.

Directed Acyclic Graph (DAG)

A set of steps connected by one-way arrows with no loops. AgentSkillOS uses one to plan a task: each skill is a step, an arrow means one skill needs another's output, and steps with no dependency on each other can run at the same time.
